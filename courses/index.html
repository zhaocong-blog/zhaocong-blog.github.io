Study guide · 课程目录

这份目录描述本站已有内容和建议阅读顺序，不代表完整课程或官方考试范围。中文与英文笔记保留原语言。

Mathematics · 数学

Algebra · 代数

建议先修：矩阵运算、向量空间与线性映射。

阅读路线：从课程介绍进入不变子空间与典范形，再学习实、复内积空间及相关变换。

Algebra Ⅱ 目前只有课程介绍；现有笔记侧重线性代数与内积空间。

  1. Introduction to Algebra Ⅰ Course
  2. BAⅡ-2.3不变子空间与特征向量
  3. B.A.Ⅱ 2.4若尔当标准型
  4. B.A.Ⅱ3.1欧几里得向量空间
  5. B.A.Ⅱ.3.2埃尔米特向量空间(酉空间)
  6. 丘.10.4.正交变换与对称变换
  7. 丘.10.5.酉空间,酉变换,Hermite 变换,正规变换
  8. 丘.10.6正交空间与辛空间
  9. 丘.10.7 正交群,酉群,辛群
  10. Introduction to Algebra Ⅱ Course

Analysis & calculus · 分析与微积分

建议先修：一元微积分基础；多元部分需要线性代数。

阅读路线：先复习函数极限和欧氏空间拓扑，再读微分学、积分与流形。

  1. Introduction to Analysis Ⅱ Course
  2. 函数极限
  3. Rn的拓扑
  4. 微分学
  5. 定积分的应用
  6. 反常积分
  7. 重积分
  8. 流形上的微分学

Measure theory · 测度论

建议先修：集合、实数、极限与基础分析。

阅读路线：从课程介绍进入 Lebesgue 测度，再学习可测函数。

  1. Introduction to Analysis Ⅰ Course
  2. Lebesgue Measure
  3. Lebesgue Measurable Functions

Probability · 概率

建议先修：集合运算、微积分与基本级数。

阅读路线：事件与概率 → 随机变量与分布 → 联合分布及独立性 → 矩与生成函数 → 极限定理和随机过程例子。

  1. Introduction to Probability Course
  2. Events and probabilities
  3. Discrete Random Variables
  4. Distribution functions and density functions
  5. Multivariate discrete distributions and independence
  6. Multivariate distributions and independence
  7. Moments, and moment generating functions
  8. Probability generating functions
  9. The main limit theorems
  10. Random walks
  11. Branching processes

Computer science · 计算机科学

Algorithms & data structures · 算法与数据结构

建议先修：基础编程、递归、渐近记号。

阅读路线：先掌握基本数据结构，再比较排序与选择算法，最后学习搜索树、散列表及结构扩张。

  1. Introduction to Algorithms Course
  2. Elementary Data Structures
  3. HeapSort
  4. Quicksort
  5. Sorting in Linear Time
  6. Medians and Order Statistics
  7. Hash Tables
  8. Binary Search Trees
  9. Red-Black Trees
  10. Augmenting Data Structures

Computer architecture · 计算机体系结构

建议先修：基本程序执行过程、二进制表示和地址概念。

阅读路线：课程介绍 → 存储层次框架 → 虚拟内存。

  1. Introduction to Computer Architecture Course
  2. A Common Framework for Memory Hierarchy
  3. Virtual Memory

Operating systems · 操作系统

建议先修：基本编程、数据结构与计算机体系结构。

阅读路线：系统概览与结构 → 进程和线程 → CPU 调度 → 同步工具与实例。

  1. Introduction to Operating System Course
  2. Operating System Introduction
  3. Operating System Structures
  4. Processes
  5. Threads & Concurrency
  6. CPU scheduling
  7. Synchronization Tools
  8. Synchronization Examples
